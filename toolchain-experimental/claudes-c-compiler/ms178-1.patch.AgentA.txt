== Adopted from Agent B (audit: CORRECT, better than mine) ==
* emit_elf ordering: relax jumps FIRST (no padding exists, every branch
  picks its shortest form), then fixup alignment, then size .skips,
  then fixup + relax again. This is GAS's smallest fixed point. The
  previous order (skips first) over-padded FILL_RETURN_BUFFER-shaped
  regions by 1 byte: recorded origlen=0x1a where GAS says 0x19
  (objtool: 'weirdly overlapping alternative'). The sev.o shape (jmp
  ACROSS two paddings — what the old order protected) stays correct:
  the second relax pass re-patches those displacements. PROOF: both
  shapes diff-identical to GAS; asm_alt_skip_relax_order.c asserts
  orig_len == real symbol distance at runtime.
* GAS \@ pseudo-variable: process-global AtomicU64 invocation counter.
  Previously unsubstituted: every kernel ANNOTATE expansion defined the
  SAME .Lhere_\@ label and all .discard.annotate_insn entries pointed
  at one address (objtool: 'intra_function_call not a direct call').
  PROOF: reloc dump now identical to GAS (.text+1,+2,+3, was +3,+3,+3).
* Directive-vs-macro guard: macros named like directive words can never
  capture '.type f, @function' (GAS resolves directives first).

== Fixed: upstream regression from B's directive-mnemonic guard ==
* resolve_set_expr treated ANY '.'-leading token as a directive
  mnemonic and skipped substitution. The .set VALUE arrives as a bare
  token ('.Lfound+1', no whitespace), so it was consumed whole:
  '.set .Lfound, .Lfound+1' silently kept 0, and the kernel's
  extable_type_reg register scan (.irp + .ifc counting into .Lfound)
  failed on EVERY uaccess object with 'extable_type_reg: bad register
  argument' (kernel/fork.o, arch/x86/events/core.o, ...). Mnemonic
  protection now applies only to pure .ident tokens outside the .L
  local-symbol namespace; '.type'/' .text' stay protected, '.Lfound+1'
  substitutes. PROOF: .set increment 0->1 matches GAS; extable shape
  assembles; directive shadow test still passes.

* i686: pusha/pushal/popa/popal (60/61) + pushaw/popaw (0x66 forms) —
  kernel realmode BIOS trampolines (arch/x86/boot/bioscall.S).
* i686: R_386_16 for .word symbol refs; REL addend patching is now
  width-correct (2-byte patch for 2-byte slots — a 4-byte write
  clobbered the neighboring field). The kernel relocs tool whitelists

* x86-64: vpblendvb with MEMORY rm operand (VEX /is4 m128/m256) —
  crc-pclmul-template.S blends the final partial vector from memory.
* x86-64: suffix-less crc32 (width from source register — kernel

* Parser: transitive .set register aliases (CONSTS -> V7 -> %xmm7 via
  .irp in crc-pclmul-template.S), resolved eagerly at definition time
  so later redefinition of the middle link cannot rewrite history.

+ *
+ * The kernel vDSO needs this form — it is userspace code that cannot
+ * reference the kernel's __x86_indirect_thunk_* symbols, so thunk-extern is

+ * indirect call/jump (same results, same stack discipline) while never
+ * executing a naked `call *%reg`/`jmp *%reg`.
+ *
+ * Runtime checks: indirect calls through function pointers (call form),
+ * a switch dense enough for a jump table (indirect jmp form), deep
+ * call chains (RSB discipline: the rewritten return addresses must not
+ * corrupt the real ones), and correct argument/return passing throughout.
+ */
+#include <stdio.h>
+
+__attribute__((noinline)) static int add1(int x) { return x + 1; }
+__attribute__((noinline)) static int mul2(int x) { return x * 2; }
+__attribute__((noinline)) static int sub3(int x) { return x - 3; }
+
+static int (*table[3])(int) = { add1, mul2, sub3 };
+
+__attribute__((noinline)) static int dispatch(int which, int v)
+{
+	/* Dense switch: eligible for a jump-table lowering, whose dispatch is
+	 * an indirect JMP that must also be retpolined. */
+	switch (which & 7) {
+	case 0: v += 10; break;
+	case 1: v += 20; break;
+	case 2: v += 30; break;
+	case 3: v += 40; break;
+	case 4: v += 50; break;
+	case 5: v += 60; break;
+	case 6: v += 70; break;
+	case 7: v += 80; break;
+	}
+	return v;
+}
+
+__attribute__((noinline)) static int chain(int depth, int v)
+{
+	if (depth == 0)
+		return table[v % 3](v);
+	return chain(depth - 1, v) + 1;
+}
+
+int main(void)
+{
+	int v = 0;
+	/* Call form through every table slot. */
+	for (int i = 0; i < 3; i++)
+		v += table[i](10);      /* 11 + 20 + 7 = 38 */

+		printf("FAIL calls v=%d\n", v);
